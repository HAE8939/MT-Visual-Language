01

排版 Typography

字体先负责建立信息秩序。层级靠字重 + 对比度，不靠字号堆叠——字号阶梯刻意收小。
Display · 28–32 / 600 · 字距 −1%
H1 · 20 / 600 — 标题只比正文大一点
H2 · 17 / 600 — 次级标题
H3 · 15 / 600 — 与正文同尺寸，只靠字重区分
Body · 15 / 400 / 1.7（中文 1.75–1.9）· 西文 ≤68ch / 中文 33–40 字。中英混排 English inline 留 1/4 空隙、不跳基线、不换行突兀。
Label / Caption · 12–13 / 400 / secondary — 元数据、注释、时间戳
Code / Prompt · 14 / 等宽 / sunken 底 · 6px 圆角
强调（选中 / 运行中）：字号永远不动，只把 400 → 600。例如同行里 这一句被强调，但和周围一样大。
§3字号只此六档、字重只此两档（400/600）；禁止靠放大字号制造"气场"，不为追求高级而擅改字号 token。
中文段落排版 · 细则见 §3.1

这是一段按中文细则设置的正文，用来对照观感。中文与西文 CSS、数字 33–40 之间留约 1/4 空隙（盘古之白），标点用全角，行首避头尾。强调走字重而非斜体——斜切的汉字会破坏方块节奏。段落不缩进、用段间距分组；正文左对齐，不做两端对齐，否则中文词间无空格会被拉出难看的缝隙。

✗ 反例使用CSS布局，行高1.5，两端对齐，斜体强调，字距+0.05em。
✓ 正例使用 CSS 布局，行高 1.8，左对齐，字重强调，字距 0、避头尾。
§3.1字体栈须含 Microsoft YaHei（否则 Windows 中文掉宋体）；行长按汉字 33–40、行高 1.75–1.9、左对齐禁 justify、全角标点 + 避头尾（line-break:strict）、强调不用斜体。

三种角色 · 悬停 / 按下 / 聚焦可实时体验
